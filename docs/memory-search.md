# Search global subject memory

Use the same Global subject memory section in the browser companion (with its configured loopback helper) or Electron. Connect using the existing protected wired USB/SSH setup, select Read tablet state, enter a nonblank query and choose Search global memory. Up to2048 UTF8 bytes are accepted. Search only queries the tablet configuration's memory profile and global facts; it does not edit/forget facts or inspect native documents. No separately installed SDK, model key, provider account, running Buddy API or Wi-Fi route is required.

Results show original fact/provenance, confidence and optional expandable identity details. These are author-asserted contextual facts, not source-verified truth or an exhaustive inventory. Complete-empty is distinct from partial, disabled, busy, unavailable or unsupported input. Busy does not stop the service: retry later or use the documented manual maintenance workflow. Cancelling, replacing the query or disconnecting clears visible results; a late response cannot restore old facts.

The supported backend contract is the delivered [offline maintenance CLI](https://github.com/s116821/ReMarkableBuddies/blob/c5fc97514193dcd4936bc0e16530dba2a1f4f482/docs/memory-query-stdin.md). Its [setup guide](https://github.com/s116821/ReMarkableBuddies/blob/c5fc97514193dcd4936bc0e16530dba2a1f4f482/docs/host-memory.md) requires the existing explicit memory profile and disabled legacy sync; selected memory additionally needs the already configured matching SharedGroup selection. The host CLI does not activate memory in the ordinary Reader loop. Installed older builds can reject the stdin marker as invalid input; the UI reports unsupported query input, never empty success. No release-version threshold is fabricated. Missing browser helper/host setup stays unavailable. A successful wired observation only permits a capability probe, not installation or native authority.

## Manual equivalent and limits

Use the existing configured Reader command `reader-buddy --memory-operation query --memory-input -`, send its exact Query JSON on stdin, then close stdin. See the linked backend guide for fields/examples, file-input alternative and setup. Profile comes from existing config. The Manager sends document:null, current_claims:[],8matches/8192context bytes and a host-generated expiry timestamp; no caller command/path/profile/provider is accepted. Raw query text is never an argv, URL, diagnostic or saved host preference.

The backend accepts up to1MiB input and has a larger generic response bound. Manager intentionally refuses backend stdout over128KiB, invalid UTF8/duplicate or malformed JSON, nonzero exit and incomplete reports. The host request cap is16KiB; trusted outer envelope cap139264 bytes includes observation overhead. Python owns a12s process deadline with an8s channel collection deadline and2s channel I/O timeout; Node guard13s and browser14s. These are consumer bounds, not a remote rollback or a guarantee that normal Store recovery performs no writes. Cancellation closes owned host work; no mutation/cleanup/restore retry is attempted. Host/session/boot checks repeat around the fixed command.
