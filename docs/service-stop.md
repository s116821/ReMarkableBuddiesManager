# Buddy service stop controls

Both companions expose **Open Buddy stop controls** and **Review stopping Buddy**.
No production installation is currently qualified. Review reports that limitation
and does not offer a Stop button. Observed metadata or a matching file hash cannot
enroll a tablet. No setting or readiness file enables the action.

The implementation separates a stop request accepted by the operating system,
a current service-state observation, and native restoration. These are different
facts. An inactive service does not establish application cleanup, durable data
flush, stock Reader restoration or the outcome of an earlier uncertain request.
Existing maintenance operations retain their own guards.

The reviewed future action targets only `reader-buddy.service` over the verified
wired connection. It does not promise an atomic stop of one historical PID.
Observed connection, boot, invocation or profile drift refuses. Local **Stop
waiting** cannot cancel a systemd job already submitted. No automatic retry,
force-kill fallback, recovery, service restart or follow-on maintenance is allowed.

The source includes strict public/private boundaries, host history and cancellation,
shared maintenance ownership, guarded browser/Electron routes and a controller
loaded on demand. Local synthetic fixtures exercise possible submission and
uncertainty. The production transport rejects Stop before opening a channel; its
review uses the existing read-only inspector and returns unqualified, without
collecting or trusting new native ownership facts.

Remaining implementation and release gates include a qualified fixed-path sampler
and submission adapter bound to the accepted deployed tuple, exact ordinary versus
resident artifact/policy admission, actual all-mode/native shutdown and recovery
qualification, independent review and final Linux/Windows package checks. Neither
profile is enabled by source/fixture tests. The central `stop-buddy-service` change
remains active until those gates and coordinated delivery are complete.
